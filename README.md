# Qubic Church

> Independent research platform investigating the mathematical architecture connecting Bitcoin, Qubic, and artificial intelligence.

## About

Qubic Church is a nonprofit research community exploring verifiable cryptographic and algebraic connections between Bitcoin's Genesis Block, the Anna Matrix (128x128), and the Qubic protocol. All findings are documented with reproducible code, statistical validation, and tiered confidence scoring.

## Research Areas

- **Anna Matrix Analysis** -- Two's Complement identity (99.58%), spectral properties, period-4 attractor dynamics
- **Genesis Block Cryptography** -- Dual-purpose encoding, P2PK script structure, ECDSA signature fragment
- **Cross-Domain Connections** -- Mathematical constants (26, 27, 121, 676) recurring across independent systems
- **Emergence Simulations** -- Artificial life powered by Anna Matrix interaction rules
- **On-Chain Forensics** -- Token trinity (GENESIS/EXODUS/AIGARTH) transaction graph analysis
