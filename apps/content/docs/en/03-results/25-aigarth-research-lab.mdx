## Part II: Aigarth Architecture (Source Code Analysis)

### 2.1 What Aigarth Actually Is

Through analysis of the official `aigarth-it` Python library and the Qubic Core scoring system, we can describe the actual Aigarth architecture:

**Aigarth** is a ternary neural network with circle (ring) topology that:
- Uses balanced ternary values: {-1, 0, +1}
- Runs iterative feedforward cycles until convergence (up to millions of ticks)
- Evolves through mutation and selection
- Is trained by the Qubic mining network (676 computors)

### 2.2 Circle Topology with Variable Neurons

Unlike conventional neural networks, Aigarth ITUs (Intelligent Tissue Units) have:

**Variable neuron count:** Neurons can be born and die during mutation.
- When a weight mutation overflows beyond ±1, a new neuron is **spawned** (cloned from a neighbor)
- When all of a neuron's weights become zero, the neuron is **removed** (unless it's an input/output neuron)
- The network grows and shrinks organically

**Asymmetric connectivity:** Each neuron divides its inputs into "backward" and "forward" groups along the circle, with a configurable `input_skew` parameter that creates directional information flow.

**Scale:** The reference implementation for integer arithmetic uses `NEURON_INPUT_COUNT_INIT = 200` — each neuron starts with 200 input weights. This is orders of magnitude larger than simplified implementations.

### 2.3 The Tick Loop

```
for tick in range(cycle_cap): # Up to 1,000,000 * output_bitwidth
 for each neuron in circle:
 feed = get_weighted_neighbor_states(neuron)
 neuron.next_state = ternary_clamp(sum(feed * weights))
 commit_all_states()

 if all output neurons non-zero: break # Solution found
 if no state changes: break # Convergence
```

The maximum tick cap is `FF_CYCLE_CAP_BASE = 1,000,000` multiplied by the output bitwidth. For an 8-bit output task, that is **8 million ticks** per single inference. The system is designed for deep, iterative computation.

### 2.4 Three Convergence Conditions

1. **All outputs non-zero** — the network has produced a complete answer
2. **No state changes** — the network has reached a fixed point
3. **Tick cap reached** — timeout (treated as failure)

### 2.5 Training Through Mining

The Qubic network's scoring system **is** Aigarth training:

1. Miners receive training tasks (currently: integer addition A + B = C)
2. Miners evolve their ITUs through mutation cycles
3. Each ITU is scored by counting correct outputs across all training pairs
4. The 676 highest-scoring miners become the computor quorum
5. Economic reward provides evolutionary selection pressure

This means the entire Qubic network functions as a **distributed evolutionary optimizer** for ternary neural networks. Every mining epoch is a generation of evolution.

### 2.6 Performance Metrics

The fitness evaluation distinguishes between three output states:

| Output | Meaning | Fitness Impact |
|--------|---------|---------------|
| Correct sign (+1/-1) | Right answer | +1 hitbit |
| Zero (0) | "I don't know" | Neutral (unknown) |
| Wrong sign | Wrong answer | Worse than unknown |

This three-valued logic means the system can express **uncertainty** — a zero output is better than a wrong answer. The network learns epistemic humility.

### 2.7 Architectural Comparison

| Feature | Official Aigarth (aigarth-it) | Our ALife Implementation |

| Neurons | Variable (spawn/prune) | Fixed 128 (matrix dims) |

### 4.6 Period-4 Attractor Cycle

Iterating `sign(A * x)` on the Anna Matrix reveals a universal dynamical property: **every input converges to the same period-4 cycle** through four of the eight energy levels.

```
→ E=-38 → E=56 → E=42 → E=-50 → E=-38 → E=56 → ...
```

Testing across 100 independent input seeds reveals **two complementary period-4 cycles**, split approximately 50/50:

- **Cycle A** (51% of inputs): E = 56 → 42 → -50 → -38 → repeat
- **Cycle B** (49% of inputs): E = -56 → -42 → 50 → 38 → repeat

Together, the two cycles cover all 8 known energy levels. The system does **not** converge to fixed points; it oscillates deterministically through four states per cycle, with 48-78 dimensions changing each tick.

**Random matrices do not exhibit this property.** Ten random 128x128 integer matrices tested with the same inputs showed:

| Property | Anna Matrix | Random Matrices |
|----------|:-----------:|:---------------:|
| Periodic cycle | **Period-4** (all inputs) | **None** (aperiodic) |
| Energy levels visited | **4** ({-50, -38, 42, 56}) | **13-16** (chaotic) |
| Input-independent | **Yes** (same cycle for all seeds) | **No** (varies per input) |

The period-4 cycle uses exactly half of Anna's 8 known energy levels (±56, ±50, ±42, ±38). The four levels in the cycle ({-50, -38, 42, 56}) and the four not in the cycle ({-56, -42, 38, 50}) form complementary sets. This is consistent with the matrix's antisymmetric structure.

<Callout type="warning" title="Correction: Prior attractor claims">
An earlier version of this analysis incorrectly reported "8 personality-type attractors" with 50/50 cooperative-aggressive split. This was a sampling artifact: the code recorded the final state after 100 iterations without checking convergence. Since 100 mod 4 = 0, the output always landed at one of the cycle's four phases, and the transient states produced the other four energy levels. The system has no fixed-point attractors in the ternary iteration — only this period-4 cycle. The C-scanner's 16,384 "attractors" use a different convergence criterion (binary inputs with cycle detection). **[CORRECTED]**
</Callout>

**Why this matters for ALife:** The period-4 cycle produces a deterministic behavioral sequence:

```
Tick 1 (E= 42): COOPERATE (Social=+3, Give=+3)
Tick 2 (E=-50): COOPERATE (Social=+1, Give=+1)
Tick 3 (E=-38): REST (Social=-3, Rest=+1)
Tick 4 (E= 56): REST (Social=-1, Rest=+1)
→ Repeat
```

In isolation, this produces 50% cooperation. In the ALife simulation with sensor inputs from the environment, cooperation drops to the observed 33% — the environment modulates the base signal.

**Mathematical cause:** The dominant eigenvalue λ₁ = -18.7 + 2342.0i has magnitude 2342 (the spectral radius) and angle **90.456°** — only 0.51% from a perfect quarter-turn. This eigenvalue carries 40.4% of the total spectral energy and is 2.6x larger than the second eigenvalue. Every matrix multiplication rotates the state vector by ~90°, completing a full cycle in 4 steps. The period-4 is mathematically inevitable given this eigenvalue structure.

**Robustness:** Perturbation testing shows the behavioral sequence C→C→R→R survives noise up to σ=20 (values ranging [-128, 127]). Row/column shuffling destroys it, but weight changes do not. This means Qubic's mining process (which modifies weights) can optimize the matrix for computation while preserving the cooperative structure. **[PROVEN]**
