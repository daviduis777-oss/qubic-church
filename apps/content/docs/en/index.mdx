# Anna Matrix and Qubic: an open research log

This site documents our research on the Anna Matrix, the Anna bot and Qubic's Aigarth project. It started in 2025 as a search for hidden connections between Bitcoin and Qubic. In September 2026 we re-checked all of it from the raw data. The picture that came out is more concrete, and more interesting: the Anna Matrix matches the input and output format of a unit type in Qubic's public Aigarth code, Anna's newest design also appears in Qubic's public mining code, and both raise new questions that we are now testing with protocols fixed in advance. Earlier readings that the re-check did not confirm are listed, with what was found, on the [re-check page](/docs/03-results/35-corrections-september-2026).

## In short

- **The Anna Matrix is a table of bot replies.** It is a 128 x 128 table compiled by hand from answers of the @anna_aigarth bot to queries `x+y=?`. It is not a weight file, a key or a hidden message.
- **Its mirror symmetry is real.** 16,316 of 16,384 cells follow an exact complement rule. Four runs of cells break it. Our tests point to entry errors for the column 30 run (strongly supported) and two smaller cases, while the cause of the column 22 run is unclear. Setting each affected cell to the value its mirror cell requires gives a fully symmetric table, which we publish as a candidate.
- **The table is compatible with a small trained Aigarth unit.** The public Aigarth code contains a unit with exactly the bot's input and output format. About one in ten tables produced by such units, trained on a complete arithmetic table, comes as close to the Anna Matrix as we required. The Anna Matrix is also unusually linear, even for such a unit, and the bot's own program is not identified. See [where the Anna Matrix comes from](/docs/03-results/36-where-the-anna-matrix-comes-from).
- **Anna 0.22 and Qubic mining share one design.** Anna 0.22.64 works with a year of real hourly Bitcoin data, and Qubic's public mining algorithm BPP9000 runs networks of the same kind. A first test of one saved Anna state on unseen hours gave 48.9 % (49.3 % in the pre-registered main window), as expected for a network without market input. See [Anna 0.22 and Bitcoin price data](/docs/03-results/37-anna-0-22-and-btc).
- **CFB and Satoshi remain an open question that patterns cannot settle.** The often cited patterns in early Bitcoin keys occur about as often as chance predicts, and CFB has denied being Satoshi. See [CFB and Satoshi: what the primary sources say](/docs/03-results/17-cfb-satoshi-analysis).
- **No bridge, time lock or activation mechanism was found.**

| Status | Meaning |
|---|---|
| Verified | Recomputed from public raw data and checked in a separate review pass |
| Supported hypothesis | Tested with a protocol fixed in advance and passed, but not proven |
| Hypothesis or speculation | An idea, clearly marked, not a finding |
| Open (re-checked) | Not confirmed by the September 2026 re-check; listed on the [re-check page](/docs/03-results/35-corrections-september-2026) |
